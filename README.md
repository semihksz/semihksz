## 💼 Ne Yapıyorum

- **Backend Mimarisi:** Laravel projelerinde Interface/Service/Repository katmanlarını kullanarak sürdürülebilir ve test edilebilir kod yazıyorum.
- **Performans & Ölçeklenebilirlik:** Laravel Octane (Swoole), Redis cache/queue yönetimi ve Meilisearch entegrasyonlarıyla yüksek trafikli sistemler üzerinde çalışıyorum.
- **Test Odaklı Geliştirme:** Pest/PHPUnit ile TDD (Red-Green-Refactor) yaklaşımını uyguluyorum.
- **Gerçek Zamanlı Sistemler:** Laravel Reverb ile WebSocket tabanlı bildirim ve canlı veri akışları geliştiriyorum.
- **DevOps:** Docker network yapılandırmaları, Nginx tabanlı API Gateway kurulumu ve GitHub Actions ile CI/CD süreçleri kuruyorum.
- **Frontend:** React, Next.js ve TypeScript ile modern, SEO uyumlu arayüzler geliştiriyorum.
- **Git Akışı:** main/dev/feature/release/staging branch stratejisiyle takım içi geliştirme süreçlerini yönetiyorum.
